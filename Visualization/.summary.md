# Camera Trajectory 3D Visualization - Implementation Summary

## Overview

This implementation provides a complete web-based solution for visualizing and analyzing camera pose trajectories in 3D space. The tool is designed to integrate seamlessly with the MAC-VO visual odometry system.

## Technical Implementation Details

### Data Format Support

**TXT Format:**
```
FRAME_ID, RIG_ID, QW, QX, QY, QZ, TX, TY, TZ
```
- CSV-like format with comments (# lines ignored)
- Quaternion in W-first convention
- Translation in meters

**NPY Format:**
- Shape (N, 7): `[tx, ty, tz, qx, qy, qz, qw]`
- Shape (N, 8): `[timestamp, tx, ty, tz, qx, qy, qz, qw]`
- Quaternion in W-last convention (PyTorch/NumPy standard)
- Auto-detection of format from header

### 3D Visualization Architecture

**Scene Setup:**
- Perspective camera with 60° FOV
- Orbit controls with damping
- Grid helper (100x100 units)
- Axes helper (5 units)
- Ambient + directional lighting

**Rendering Pipeline:**
1. Parse input file
2. Create trajectory line geometry
3. Sample and place camera markers
4. Create current camera indicator
5. Auto-fit camera to trajectory bounds
6. Continuous render loop with controls update

**Performance Optimizations:**
- Marker sampling for large datasets
- BufferGeometry for efficient rendering
- RequestAnimationFrame for smooth playback
- Lazy loading of 3D objects
- Efficient distance calculation caching

### Distance Calculation

**Total Distance:**
```javascript
sum(distance(pose[i], pose[i+1])) for i in 0..N-1
```

**Range Distance:**
```javascript
sum(distance(pose[i], pose[i+1])) for i in start..end-1
```

Uses Three.js `Vector3.distanceTo()` for Euclidean distance.

### Playback System

**Frame Update Logic:**
- Timer-based with adjustable FPS
- Automatic loop from start to end frame
- Progress tracking with visual feedback
- Synchronized UI updates

**Controls:**
- Play: Starts animation loop
- Pause: Stops animation, maintains current frame
- Reset: Jumps to start frame, stops animation
- Slider: Direct frame selection with pause

## Integration with MAC-VO

The tool integrates with MAC-VO's output format:

1. MAC-VO saves poses to `sandbox/poses.npy` with shape (N, 8)
2. Export script converts to visualizer format
3. Web tool loads and visualizes the data

**Data Flow:**
```
MAC-VO Experiment
    ↓
Sandbox (poses.npy)
    ↓
export_trajectory.py
    ↓
trajectory.txt/.npy
    ↓
camera_trajectory_3d.html
    ↓
Interactive 3D Visualization
```
